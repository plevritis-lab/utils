# differential_testing

this module provides scripts for comparing spatial features (colocalization, topology, proportions) between conditions or groups.

## directory structure

- `compare_local_colocation.py`: python script for comparing local colocalization metrics between groups.
- `compare_topology.py`: (placeholder) script for comparing topological features between groups.
- `compare_proportions.py`: python script for comparing cell type proportions between groups.

## usage notes
- these scripts are designed for statistical comparison of spatial features, supporting hypothesis testing and figure generation.
- can be used independently or as part of a larger analysis pipeline.

## directory structure changes
- the module is organized as a flat directory of comparison scripts, each focused on a specific spatial feature.
